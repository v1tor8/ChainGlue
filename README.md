# ChainGlue

ChainGlue: A decentralized, real-time blockchain aggregator and data manager for high-performance cluster operations.

With ChainGlue, you get a lightweight tool that stays out of your way.

**What you get**

- ChainGlue: A decentralized, real-time blockchain

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainGlue.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
